# Review — ut-plugin-integration-ai 2.0.0: the AI engine as a WASM plugin (ut-docs#4032)

Part of ut-docs#2851 (move the AI engine out of core). Built by Opus 5.5
(Dev subagent); independent review by Fable; driven run by a Tester
subagent; fixes applied by the orchestrating lane (lane:cloud-24).

## What shipped

- `runtime: "wasm"` Go plugin on the guest SDK (`universal-till/sdk/plugin`,
  pinned by pseudo-version of universal-till `9b625c12` — the `v1.0.0` tag
  lacks `ItemImageOpen`; tag follow-up ut-docs#4033).
- `src/ai`: port of the till's `internal/ai` — Ollama / OpenAI / Claude
  providers, identify prompt + schema, hallucination filter, Ask tool loop
  (6 rounds, 120 s budget), 401/403 body suppression (now Claude too).
- `src/app`: `catalog.identify` job → `suggestions` (`add_to_basket`),
  `catalog.identify.confirmed` ack, `reports.panels` Ask panel → action →
  `com.universaltill.integration-ai.ask` job over the five core Ask views;
  settings resolution (exact `claude`/`openai`, else self-hosted;
  hosted-without-key = not configured).
- Manifest 2.0.0: same id, keys and defaults (`endpoint` now
  `type: "endpoint"`), permissions `events:receive`, `view:sales`,
  `view:inventory`, `view:audit`, `ui:page`, `ui:slot:reports.panels`,
  `net:@setting:endpoint`, `http:lan`, `net:api.openai.com`,
  `net:api.anthropic.com`; `limits.long_call_s: 120`.
- Locale bundle en/ar/fa/tr; build/package/validate/publish scripts and
  CI/release workflows modelled on ut-plugin-tax-de; version-bump guard now
  covers `src/`, `locales/`, `go.mod`.

## Findings

| # | Severity | Finding | Outcome |
|---|---|---|---|
| S1 | should-fix (high) | The till's plugin HTTP client cuts off a response whose headers take > 30 s; Ollama `stream:false` sends headers only at the end, so a slow self-hosted vision call fails where core waited 90 s. Code comments and docs claimed 120 s. | Not fixable plugin-side. Comments, README "Known limits" and `architecture/ai-plugin.md` corrected; core card **ut-docs#4035** (p1, Ready) filed and made a dependency of #2851. |
| S2 | should-fix (low) | Hiding the Ask panel by not answering logs a till warn per Reports load. | Accepted (hiding matches core's behaviour); documented in README. |
| S3 | should-fix | `validSKU` looser than the till's `hasControl` (C1 controls): one bad SKU would void the whole identify answer. | Fixed: `utf8.ValidString` + `unicode.IsControl`; C1 case added to `TestIdentify_LabelsAndSKUsWithinFormatLimits` (failed before the fix). |
| D1 | minor (Tester) | No-match showed twice: the plugin's notice and the till's own "No match found". | Fixed: the plugin adds no notice when there are no suggestions; key removed from all locales; two tests updated first (failed before the fix). |
| N1 | nit | WebP / > 4 MiB photos refused though the seam admits them. | Accepted: the overlay sends ≤ 1024 px JPEG; matches what the till stores. |
| N2 | nit | README didn't say plain `http://` is loopback/LAN only. | Fixed. |
| N3 | nit | `ErrBusy` on `item_image_open` burnt the 64-open quota. | Fixed: break on `ErrBusy` too. |
| N4 | nit | No shop name/currency for the Ask prompt. | Card **ut-docs#4034** filed. |

## Verified beyond unit tests

- Reviewer re-verified 5 TDD claims by breaking the code in a worktree
  (arg clamp, 64-open cap, auth-body suppression, hallucination filter,
  SKU rule) — each test failed, then passed when restored.
- Manifest accepted by the till's own `ParseManifest` / `VerifyManifest` /
  `PersistManifest`; all sample answers accepted by `pluginview` decoders,
  including in the identify seam context.
- **Driven run** (Tester, universal-till main `9b625c12`, Playwright +
  Chromium, fake camera, stub Ollama on loopback): import 2.0.0 → grants →
  Ask panel on Reports → question → job → `sales_by_day` tool round trip →
  answer shown; sell screen shows only the plugin's Identify button →
  capture → two suggestions → tap → line added, `ai_ref` stored and
  `ai_identify_confirmed` audited; provider down → Ask notice and
  "Identification failed", sale still tenders; recovery without restart;
  disable / uninstall → button and panel gone. Screenshots checked by the
  orchestrator (identify suggestions overlay; Reports with both Ask cards).
- Known, accepted while both engines exist: Reports also shows the till's
  built-in Ask card (removed by #2851).
